# 📧 MailAI – AI-Powered Email Assistant

MailAI is an AI-powered email management web application that integrates with Gmail and allows users to manage their emails through both a traditional mail interface and natural-language AI commands.

The application combines **React, Spring Boot, Gmail API, OAuth 2.0, and OpenAI** to provide an intelligent email experience where users can search, filter, open, compose, send, and reply to emails using simple natural-language instructions.

---

## 🚀 Features

### 📥 Gmail Integration
- Connects directly with a Google/Gmail account.
- Displays real Gmail messages inside the application.
- Supports Inbox and Sent folders.
- Uses Google OAuth 2.0 authentication.

### ✉️ Email Management
- View emails from Gmail.
- Open an email to view its complete content.
- Compose new emails.
- Send emails through Gmail.
- Reply to the currently opened email.

### 🤖 AI Email Assistant

Users can control the application using natural-language commands.
